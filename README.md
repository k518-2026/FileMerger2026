# ファイル統合ツール（FileMerger）

複数のファイルを 1 つにまとめる Windows デスクトップアプリです。
ファイルの種類を見て、適した統合方法を自動で選びます。

- .NET 8 / Windows Forms（C#）
- Visual Studio 2022 でそのまま開けるソリューション

## 対応している統合

| 統合方法 | 入力 | 出力 |
| --- | --- | --- |
| PDF を 1 つに結合 | `.pdf` | 1 冊の PDF（ページ順に連結） |
| 画像を 1 つの PDF にまとめる | `.jpg` `.jpeg` `.png` `.bmp` `.gif` `.tif` `.tiff` `.webp` | PDF（1 枚 1 ページ、複数ページ TIFF も展開） |
| Excel ブックを結合 | `.xlsx` `.xlsm` `.csv` `.tsv` | `.xlsx`（シート別／1 枚のワークシートに縦・横連結） |
| Word 文書を 1 つに結合 | `.docx` | `.docx`（書式を保ったまま連結） |
| PowerPoint を 1 つに結合 | `.pptx` `.pptm` | `.pptx`（スライドをデザインごと取り込み） |
| CSV / TSV を 1 つの表に結合 | `.csv` `.tsv` | `.csv`（見出し行の重複を除去、出所列を追加） |
| テキストとして結合 | `.txt` `.md` `.log` `.json` `.xml` `.html` `.css` `.js` `.sql` `.yaml` `.srt` ほか | `.txt`（ファイル名の見出し付き） |
| そのまま連結（バイナリ） | 何でも | 中身を解釈せず先頭から連結（分割ファイルの復元など） |

## Excel の連結方法

[Excel の並べ方] から 4 つのうち 1 つを選びます。

| 方法 | 動き | 向いている場面 |
| --- | --- | --- |
| シートごとに分けて入れる | 入力ブックのシートを書式・数式ごと 1 冊に集める | 元の見た目を崩したくないとき |
| 1 枚のシートに縦連結（列の位置どおり） | 左から数えた列位置をそのまま合わせて下へ積む | 同じテンプレートで作られた表 |
| 1 枚のシートに縦連結（見出し名で列をそろえる） | 1 行目の見出し名を突き合わせ、列の順番や有無が違っても正しい列へ入れる | 支店ごと・月ごとに列が微妙に違う表 |
| 1 枚のシートに横並び | ファイルごとのブロックを右へ並べる | 期間や条件を横に見比べたいとき |

縦連結の 2 つは、複数シートを持つブックでもシート単位に分解して 1 枚へまとめます。
併せて次のオプションが効きます。

- **「元ファイル」列を追加する** … 各行の末尾にどのファイル由来かを残します。集計後にピボットで分けられます。
- **2 つ目以降の見出し行を繰り返さない** … 列の位置どおりモードでのみ使います。見出し名でそろえるモードは 1 行目を常に見出しとして扱うため、設定は不要です。
- **ファイルの区切りに空行（横並びでは空列）を入れる** … 目視で区切りたいときに。集計に回すならオフを推奨します。

見出し名でそろえるモードでは、どのファイルにも無い列は空欄になり、見出しが空のセルは `列3` のように位置で名前が付きます。

## ビルドと実行

```
git clone <このフォルダー>
cd FileMerger
dotnet restore
dotnet build -c Release
dotnet run --project FileMerger
```

Visual Studio の場合は `FileMerger.sln` を開いて F5。
初回ビルド時に NuGet から次のパッケージが復元されます。

- PdfSharp 6.1.1
- ClosedXML 0.104.2
- DocumentFormat.OpenXml 3.1.1
- System.Text.Encoding.CodePages 8.0.0

必要な環境は .NET 8 SDK（実行だけなら .NET 8 Desktop Runtime）です。

## 単一 EXE として配布する

```
dotnet publish FileMerger -c Release -r win-x64 --self-contained true ^
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

## 使い方

1. ウィンドウにファイルをドラッグ＆ドロップする（または [ファイルを追加]）
2. 並び順が結合順になるので、[▲ 上へ] [▼ 下へ] [名前順に並べ替え] で整える
3. [統合方法] は既定で自動判定。手動で切り替えることもできる
4. [保存先] を確認して [統合する]

Delete キーで選択行を削除できます。

[ヘルプ] メニューには次の 3 つがあります。

- **扱えるファイルの一覧（F1）** … 統合方法ごとの対応拡張子と出力形式。`MergerRegistry.All` から組み立てているので、統合方法を追加すれば自動で反映されます。
- **マニュアルを開く** … `docs/manual.html` を既定のブラウザーで開きます。ビルド時に出力フォルダーへコピーされます。
- **バージョン情報**

## 統合方法を増やすには

`Core/IFileMerger.cs` を実装したクラスを `Mergers/` に置き、
`Core/MergerRegistry.cs` の `All` に追加するだけです。
自動判定は `All` の並び順で先に一致したものを使うので、
限定的な機能ほど上に置いてください。

## 制限事項

- **Word**: 2 つ目以降は AltChunk として差し込みます。ファイル内には正しく格納されますが、実際の展開は Word が文書を開いたときに行われるため、Word 以外のビューアーでは 1 つ目の内容しか見えないことがあります。ヘッダー・フッターやセクション設定は 1 つ目のものが優先されます。
- **Excel**: シート別モードでは数式の参照先が別ブックのままになることがあります。値だけで良い場合は縦連結モードを使ってください。縦・横連結モードは値のみを写すため、セルの書式・結合セル・数式は引き継がれません。
- **PowerPoint**: スライドの大きさ（16:9 / 4:3）は 1 つ目のファイルのものが全体に適用されます。比率の違うファイルを混ぜると、2 つ目以降のスライドで図形の位置がずれることがあるので、比率をそろえてから統合するか、統合後に PowerPoint 側で [デザイン] → [スライドのサイズ] で調整してください。デザインの異なるファイルを混ぜた場合はスライド マスターがファイルの数だけ増えます（各スライドの見た目は元のまま保たれます）。`.pptm` を含む場合もマクロなしの `.pptx` として保存され、マクロは引き継がれません。
- **PDF**: 暗号化された PDF は開けません。しおり（ブックマーク）は引き継がれません。
- **画像**: `.webp` は Windows の GDI+ が対応していない環境があります。その場合は事前に PNG へ変換してください。
- **バイナリ連結**: 形式を無視してつなぐだけなので、MP4 や ZIP などのコンテナ形式は再生・展開できないファイルになります。分割ファイルの復元用と考えてください。
