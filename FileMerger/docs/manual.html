ファイル統合ツール

ばらばらのファイルを、種類に合ったやり方で 1 つにまとめる Windows アプリ

このアプリについて

PDF、画像、Excel、Word、PowerPoint、CSV、テキストなど、種類の違うファイルを それぞれに適したやり方で 1 つにまとめます。 追加したファイルの拡張子を見て統合方法を自動で選ぶので、 ふだんは ファイルを放り込んで [統合する] を押すだけで終わります。

「PDF を結合するソフト」「画像を PDF にするソフト」と用途ごとに使い分ける必要がなく、 並び順の入れ替えや文字コードの調整も同じ画面でできます。

動作環境と導入

OSWindows 10 / 11（64 ビット）
実行に必要なもの.NET 8 デスクトップ ランタイム（自己完結型で配布した場合は不要）
ビルドに必要なものVisual Studio 2022 または .NET 8 SDK

ソースからビルドする場合は、ソリューションを開いて F5 を押すだけです。

dotnet restore
dotnet build -c Release
dotnet run --project FileMerger

ランタイムの入っていない PC へ配る場合は、実行ファイル 1 つにまとめられます。

dotnet publish FileMerger -c Release -r win-x64 --self-contained true ^
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
インストール作業は不要です レジストリを触らず、設定ファイルも作りません。フォルダーごとコピーすれば動き、 削除したいときはフォルダーごと消すだけです。

ファイル一覧はエクスプローラーからのドラッグ＆ドロップに対応しています。 フォルダーを落とすと、その中のファイルがまとめて追加されます。 選択中の行は Delete キーで削除できます。

基本の手順

  1. ファイルを追加する ウィンドウにドラッグ＆ドロップするか、[ファイルを追加] / [フォルダーを追加] で選びます。 同じファイルを二重に追加しようとした場合は自動で除かれます。
  2. 順番を整える 一覧の上から順に結合されます。[▲ 上へ] [▼ 下へ] で動かすか、[名前順に並べ替え] を使います。 ファイル名に 01_ 02_ のような連番を付けておくと一度で並びます。
  3. 統合方法とオプションを確認する 通常は [自動で判定する] のままで構いません。判定結果は [出力の設定] の見出しに表示されます。 意図と違うときだけ手動で選んでください。
  4. 保存先を決めて [統合する] 保存先は 1 つ目のファイルと同じフォルダーに 統合結果 という名前で自動入力されます。 変更したいときは [参照...] から選び直します。
元のファイルは変更されません このアプリは読み取りしか行わず、結果は新しいファイルとして書き出します。 ただし保存先に既存のファイルを指定すると上書きの確認が出ますので、その場合はご注意ください。

統合方法ごとの説明

PDF を 1 つに結合

追加した順にページをつなぎます。ページの大きさや向きは元のまま保たれるので、 A4 と A3 が混ざっていてもそれぞれのサイズで残ります。 暗号化された PDF は開けません。しおり（ブックマーク）は引き継がれません。

画像を 1 つの PDF にまとめる

1 枚の画像が 1 ページになります。ページの作り方を 2 通りから選べます。

設定動き向いている場面
A4 に合わせる縦横比を保ったまま A4 に収め、余白を付けて中央に置く。横長の画像は自動で横向きページ。印刷して配る資料
画像と同じ大きさ画像の寸法そのままのページを作り、余白なしで貼る。画面で見るだけ、余白を入れたくないとき

複数ページの TIFF は自動で 1 ページずつ展開されます。スキャナーで読み取った書類をまとめるのに便利です。

Excel ブックを結合

[Excel の並べ方] から 4 通り選べます。CSV を混ぜて追加することもできます。

並べ方動き向いている場面
シートごとに分けて入れる入力ブックのシートを書式・数式ごと 1 冊に集める。元の見た目を崩したくないとき
1 枚のシートに縦連結
（列の位置どおり）		左から数えた列位置をそのまま合わせて下へ積む。同じテンプレートで作られた表
1 枚のシートに縦連結
（見出し名で列をそろえる）		1 行目の見出し名を突き合わせ、列の順番や有無が違っても正しい列へ入れる。支店ごと・月ごとに列が微妙に違う表
1 枚のシートに横並びファイルごとのブロックを右へ並べる。期間や条件を横に見比べたいとき

縦連結の 2 つは、複数シートを持つブックでもシート単位に分解して 1 枚にまとめます。 [「元ファイル」列を追加する] をオンにしておくと各行の末尾に由来が残るので、 統合したあとピボットテーブルでファイル別に分け直せます。

見出し名でそろえるモードでは、どのファイルにも無い列は空欄になり、 見出しが空のセルは 列3 のように位置で名前が付きます。 列名は前後の空白と大文字小文字を無視して突き合わせます。

縦・横連結は値のみを写します セルの書式、結合セル、数式、グラフは引き継がれません。見た目ごと残したい場合は [シートごとに分けて入れる] を使ってください。

Word 文書を 1 つに結合

1 つ目の文書を土台にして、2 つ目以降を差し込みます。 それぞれの書式・見出し・図はそのまま残ります。 [ファイルの区切りで改ページ] をオンにすると、文書の境目で改ページが入ります。

Word で開いたときに完成します 2 つ目以降は、Word が文書を開いた時点で展開されるしくみ（AltChunk）で格納しています。 ファイル自体は正しく作られていますが、Word 以外のビューアーでは 1 つ目の内容しか 見えないことがあります。心配な場合は一度 Word で開いて上書き保存してください。 ヘッダー・フッターやページ設定は 1 つ目の文書のものが優先されます。

PowerPoint を 1 つに結合

1 つ目のファイルを土台にして、2 つ目以降のスライドを取り込みます。 スライドが使っているレイアウト・スライドマスター・画像も一緒に写るため、 デザインの違うファイルを混ぜても各スライドの見た目は元のまま保たれます。 その分、デザインの数だけスライドマスターが増えます。

スライドの比率はそろえておく 画面サイズ（16:9 / 4:3）は 1 つ目のファイルのものが全体に適用されます。 比率の違うファイルを混ぜると 2 つ目以降で図形の位置がずれることがあります。 あらかじめそろえておくか、統合後に PowerPoint の [デザイン] → [スライドのサイズ] で調整してください。 .pptm を含む場合もマクロなしの .pptx として保存され、マクロは引き継がれません。

CSV / TSV を 1 つの表に結合

複数の CSV を 1 枚の表につなぎます。 引用符で囲まれたカンマや改行を含むデータも壊しません。

  • [2 つ目以降の見出し行を繰り返さない] … 1 行目が前のファイルと同じ見出しだったときだけ読み飛ばします。中身が違えばデータ行として扱うので、誤って 1 行消える心配はありません。
  • [元のファイル名を見出しとして入れる] … 末尾に 元ファイル 列を足し、どのファイル由来かを残します。

保存先の拡張子を .tsv にすると、タブ区切りで書き出します。

テキストとして結合

テキスト系のファイルを順につなぎます。 [元のファイル名を見出しとして入れる] をオンにすると、各ファイルの先頭に区切り線とファイル名が入るので、 あとからどこが境目か分かります。ログの集約や、原稿の統合に向いています。

そのまま連結（バイナリ）

中身を解釈せず、先頭から順にバイト列としてつなぎます。 .001 .002 のように分割されたファイルを元に戻すときに使います。

形式のあるファイルには使えません MP4 や ZIP、Office 文書などをこの方法でつないでも、再生・展開できないファイルになります。 分割ファイルの復元用と考えてください。

オプションの意味

選んだ統合方法に関係のないオプションは自動で灰色になります。文言も方法に合わせて変わります。

オプション効く統合方法意味
元のファイル名を見出しとして入れる テキスト / CSV / Excel テキストでは区切り線とファイル名、CSV と Excel では 元ファイル 列、Excel の横並びではブロック上の見出しになります。
2 つ目以降の見出し行を繰り返さない CSV / Excel（列の位置どおり） 先頭行が前のファイルと同じ見出しのときだけ読み飛ばします。
ファイルの区切りで改ページ・空行を入れる Word / テキスト / Excel Word は改ページ、テキストは空行、Excel の縦連結は空行、横並びは空列を入れます。集計に回すデータでは切っておくのが無難です。
Excel の並べ方 Excel 4 つの連結方法の切り替え。前章の表を参照してください。
画像のページ 画像 → PDF A4 に合わせるか、画像と同じ大きさのページにするか。
統合できたら保存先フォルダーを開く すべて 完了後にエクスプローラーで結果のファイルを選択した状態で開きます。

文字コードの扱い

テキストと CSV では文字コードの指定ができます。 [入力の文字コード] を [自動で判定する] にしておくと、次の順で判定します。

  1. BOM（ファイル先頭の目印）があれば、それに従う
  2. BOM がなければ、UTF-8 として正しく読めるか試す
  3. 読めなければ Shift_JIS として読む

この順序のおかげで、Windows で作った古い CSV と UTF-8 のファイルが混ざっていても、 1 ファイルずつ適切に読み分けられます。文字化けする場合だけ手動で指定してください。

Excel で開く CSV は Shift_JIS か BOM 付き UTF-8 で [出力の文字コード] を [UTF-8 (BOM なし)] にすると、Excel でダブルクリックして開いたときに 日本語が化けることがあります。Excel で開く予定なら [UTF-8 (BOM 付き)]（既定）か [Shift_JIS] を選んでください。

よくある質問

種類の違うファイルをまとめて 1 つにできますか？

PDF と Word など、形式をまたぐ変換は行いません。 まず Word 側で PDF として書き出してから、PDF どうしを結合してください。 画像と PDF を混ぜたい場合も、画像を先に PDF にしてから結合します。

結合する順番はどこで決まりますか？

ファイル一覧の上から順です。追加した順に並ぶので、 [▲ 上へ] [▼ 下へ] または [名前順に並べ替え] で調整してください。 複数行を選択したまま動かすこともできます。

意図しない統合方法が選ばれます。

自動判定は拡張子だけを見ています。[統合方法] のドロップダウンから明示的に選べば、 判定より優先されます。

大量のファイルでも大丈夫ですか？

処理は別スレッドで動くので、途中でも画面が固まらず [中止] を押せます。 ただし PDF や Excel はファイル全体をメモリに読み込むため、 非常に大きなファイルを大量に扱うと時間とメモリを消費します。

統合したファイルが Word / PowerPoint で「修復が必要」と出ます。

元のファイルが破損しているか、他のアプリが開いたままロックしている可能性があります。 すべて閉じてからやり直してください。それでも直らない場合は、 どのファイルを外すと成功するかを 1 つずつ試すと原因を特定できます。

設定は保存されますか？

現在のバージョンでは保存しません。起動のたびに既定値から始まります。

制限事項

  • 形式をまたぐ変換はしません。同じ系統のファイルどうしをつなぐツールです。
  • PDF：暗号化された PDF は開けません。しおりは引き継がれません。
  • Word：2 つ目以降は Word が開いた時点で展開されます。ヘッダー・フッターは 1 つ目が優先されます。
  • PowerPoint：スライドの比率は 1 つ目に統一されます。マクロは引き継がれません。
  • Excel：縦・横連結は値のみを写します。シート別モードでは数式の参照先が別ブックのまま残ることがあります。
  • 画像：.webp は環境によって読み込めないことがあります。その場合は事前に PNG へ変換してください。
  • バイナリ連結：形式を無視してつなぐだけなので、コンテナ形式のファイルは壊れます。

統合方法を増やす（開発者向け）

統合方法は IFileMerger という 1 つのインターフェイスにまとまっています。 実装したクラスを Mergers/ に置き、Core/MergerRegistry.cs の All に追加するだけで、コンボボックス・自動判定・[扱えるファイルの一覧] のすべてに反映されます。 

public static IReadOnlyList<IFileMerger> All { get; } = new IFileMerger[]
{
    new PdfMerger(),
    new ImageToPdfMerger(),
    new ExcelMerger(),
    new WordMerger(),
    new PowerPointMerger(),
    new CsvMerger(),
    new TextMerger(),
    new BinaryMerger()      // 受け皿なので必ず最後
};

All の並び順が自動判定の照合順です。 対象を限定する方法ほど上に、受け皿になる方法ほど下に置いてください。

MergerFeatures フラグで「どのオプションが効くか」を宣言すると、 画面側が該当するコントロールだけを自動で有効にします。 画面のコードに手を入れる必要はありません。

ファイル統合ツール マニュアル ／ 最新の対応ファイルはアプリの [ヘルプ] → [扱えるファイルの一覧]（F1）で確認できます。
